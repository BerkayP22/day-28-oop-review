# OOP tekrar uygulaması

**Gün 28 · C# günlük çalışma**

Product ve Order sınıflarını sıfırdan kurup LINQ ile toplam sipariş tutarını raporlar.

## Çalıştırma

.NET 10 SDK ile bu klasörde `dotnet run` çalıştırın.

## Tekrar soruları

Class/nesne, kapsülleme, kalıtım, interface ve LINQ kavramlarını bu örnekteki sınıflarla ilişkilendirerek açıklayın.
